# Triage Labels

工程 Skills 使用五個標準 triage 角色。本文件將角色對應至 Local Markdown tracker 中 `Status:` 使用的值。

| 標準角色 | Local tracker 值 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工實作或處理 |
| `wontfix` | `wontfix` | 不會處理 |

當 Skill 提及 triage 角色時，使用本表對應的值。若日後更改 tracker 用語，只需修改第二欄。
